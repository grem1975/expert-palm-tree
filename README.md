# Expert Palm Tree

Рабочий репозиторий для проектов, выполняемых совместно с OpenClaw и Codex.

## Роли

- **OpenClaw** — принимает запросы из Telegram, уточняет цель и формирует краткое техническое задание.
- **Codex** — изучает репозиторий, реализует изменения, запускает проверки и готовит pull request.
- **GitHub** — хранит задачи, ветки, изменения, проверки и решения.

## Как начать задачу

1. Создайте Issue через шаблон **Codex task**.
2. Укажите цель, ограничения и критерии готовности.
3. Откройте репозиторий в Codex.
4. Для серьёзной или параллельной работы используйте отдельный Worktree.
5. Попросите Codex выполнить Issue, проверить результат и подготовить PR.
6. Проверьте diff и тесты перед слиянием.

## Правила работы

- Одна задача — один измеримый результат.
- Одна ветка или worktree — один пишущий агент.
- Секреты, токены и файлы `.env` не коммитятся.
- Изменение считается готовым только после описанной проверки.
- Постоянные инструкции проекта находятся в [AGENTS.md](AGENTS.md).
- Подробный процесс описан в [docs/WORKFLOW.md](docs/WORKFLOW.md).
