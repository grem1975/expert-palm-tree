# Telegram Desktop Outreach

Локальная macOS-автоматизация для отправки заранее подготовленной очереди сообщений через Telegram Desktop без Bot API и MTProto.

Инструмент предназначен только для существующих контактов, которые ожидают сообщения. Он не ищет получателей и не добавляет новые контакты.

## Защита

- белый список `contacts.csv`;
- обязательные `enabled=true` и `opt_in=true`;
- максимум 15 отправок в сутки;
- не более одного сообщения контакту в сутки;
- журнал `state/sent.jsonl`;
- остановка после первой ошибки;
- блокировка параллельного запуска;
- по умолчанию только dry-run;
- реальная отправка требует одновременно `send_enabled=true` и флаг `--send`.

## Требования

- macOS;
- установленный и авторизованный Telegram Desktop;
- Python 3.10+;
- разрешение Accessibility для программы, запускающей скрипт.

## Настройка

Заполните `contacts.csv`:

```csv
contact_id,username,enabled,opt_in
client_ivan,ivan_username,true,true
```

`username` — публичное имя без `@`. Используются только получатели, для которых явно указано согласие `opt_in=true`.

Добавьте очередь в `queue.csv`:

```csv
send_date,contact_id,message
2026-07-12,client_ivan,"Иван, добрый день! Подготовил обещанные материалы."
```

## Проверка без отправки

```bash
python3 telegram_outreach.py --config config.json
```

## Включение автоматической отправки

1. Откройте **System Settings → Privacy & Security → Accessibility**.
2. Разрешите управление для Terminal или другого приложения, из которого запускается скрипт.
3. Перезапустите это приложение.
4. Установите `"send_enabled": true` в `config.json`.
5. Запустите:

```bash
python3 telegram_outreach.py --config config.json --send
```

Скрипт открывает официальный deep link `tg://resolve` с подготовленным текстом, проверяет, что Telegram находится на переднем плане, и нажимает Return через macOS Accessibility.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют только планирование, лимиты и ссылки. Они не открывают Telegram и ничего не отправляют.

## Автозапуск

После заполнения реальных контактов и выбора времени запуска можно добавить LaunchAgent. Не включайте расписание до успешного dry-run и одной контролируемой тестовой отправки своему контакту.
